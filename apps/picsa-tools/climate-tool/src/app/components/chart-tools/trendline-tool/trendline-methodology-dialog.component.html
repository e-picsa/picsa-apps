{{ 'What does the trendline show?' | translate }}

{{ 'A trendline shows the general long-term direction of change over time (e.g. warming temperatures, shift in seasonal rainfall). It fits an ordinary least squares regression line to historical data.' | translate }}

visibility

{{ 'Why are some lines colored, grey, or missing?' | translate }}

{{ 'A colored line indicates a statistically clear trend (p < 0.05). A grey dashed line shows an uncertain or weak trend where year-to-year variation is too high to confirm certainty. If no line appears at all, the observation record has too many missing years to calculate a reliable trend.' | translate }}

history_edu

{{ 'Use it as historical context — not a forecast' | translate }}

{{ 'The line describes past recorded history, not what will happen next season. Passing a statistical test does not tell us whether the historical change is large enough to matter for a particular farm. Always consider trends alongside seasonal forecasts, soil context, and local agricultural advice.' | translate }}

{{ 'Ordinary Least Squares (OLS) Regression' | translate }}

{{ 'Linear regression fits a straight line minimizing the sum of squared differences between historical observations and fitted values. Slopes, intercepts, Pearson correlation (r), and R² are computed using standard OLS methods.' | translate }}

{{ 'Trend Classification Criteria' | translate }}

  • {{ 'Statistically clear (colored line):' | translate }} {{ 'p < 0.05. Strong evidence that the historical rate of change is distinguished from random yearly fluctuations.' | translate }}
  • {{ 'Uncertain trend (grey dashed line):' | translate }} {{ 'p ≥ 0.05 with noticeable historical change (|r| ≥ 0.15, R² ≥ 0.02). Direction is estimated, but yearly variation is too high to rule out random chance.' | translate }}
  • {{ 'Weak / minimal trend (grey dashed line):' | translate }} {{ 'p ≥ 0.05 with negligible historical change (|r| < 0.15, R² < 0.02). Historical values fluctuate without a meaningful overall directional shift.' | translate }}

{{ 'Data Completeness Rules' | translate }}

{{ 'To prevent misleading fits, trendline estimation requires minimum inclusion thresholds based on usable years (verified complete annual or seasonal records, where missing values are never treated as zero):' | translate }}

  • {{ '10-Year View:' | translate }} {{ 'At least 7 usable years within the most recent 10-year window.' | translate }}
  • {{ '30-Year View:' | translate }} {{ 'At least 20 usable years within the most recent 30-year window.' | translate }}
  • {{ 'Full Record:' | translate }} {{ 'At least 20 usable years and at least 70% data completeness across the full record.' | translate }}

{{ 'Statistical Significance (p-value)' | translate }}

{{ 'Significance is evaluated using a two-sided Student t-test on the correlation coefficient with df = n - 2 degrees of freedom. A threshold of p < 0.05 is required for a trend to be classified as statistically clear.' | translate }}
