{{ 'What does the trendline show?' | translate }}

{{ 'A trendline summarizes the general multidecadal direction of historical change over time (e.g. warming temperatures, shift in seasonal rainfall). It fits an ordinary least squares regression line to historical records.' | translate }}

visibility

{{ 'When is a trendline displayed?' | translate }}

{{ 'A solid, coloured trendline is displayed only when the estimated trend is statistically clear (p < 0.05) and passes data quality checks. When historical records are inconclusive (p ≥ 0.05) or data is insufficient, no trendline is drawn to avoid visually asserting an unconfirmed direction.' | translate }}

history_edu

{{ 'Use it as historical context — not a forecast' | translate }}

{{ 'The line describes past recorded history, not what will happen next season. Passing a statistical test does not tell us whether the historical change is large enough to matter for a particular farm. Always consider trends alongside seasonal forecasts, soil context, and local agricultural advice.' | translate }}

{{ 'Ordinary Least Squares (OLS) Regression' | translate }}

{{ 'Linear regression fits a straight line minimizing the sum of squared differences between historical observations and fitted values. Slopes, intercepts, and R² are computed using standard OLS methods on verified calendar years.' | translate }}

{{ 'Trend Classification Criteria' | translate }}

  • {{ 'Upward trend (solid coloured line):' | translate }} {{ 'Statistically clear increase (p < 0.05) with positive slope.' | translate }}
  • {{ 'Downward trend (solid coloured line):' | translate }} {{ 'Statistically clear decrease (p < 0.05) with negative slope.' | translate }}
  • {{ 'No clear trend (no line):' | translate }} {{ 'p ≥ 0.05. Natural year-to-year variation is too large relative to sample size to establish a directional trend.' | translate }}
  • {{ 'Insufficient data (no line):' | translate }} {{ 'Record has too many missing years to calculate a reliable trend.' | translate }}

{{ 'Statistical Inference & 95% Confidence Intervals' | translate }}

{{ 'Significance is evaluated using a two-sided Student t-test on the regression slope with df = n - 2 degrees of freedom. Two-tailed 95% confidence intervals are computed to indicate the precision of the estimated decadal rate of change.' | translate }}

{{ 'Goodness of Fit (R²)' | translate }}

{{ 'R² measures the proportion of variance explained by the trend. In highly variable climate series (such as rainfall), low R² values are common even when a statistically clear and practically important trend exists. R² is therefore provided for supplementary context, not used to accept or reject trendline display.' | translate }}

{{ 'Data Completeness Rules' | translate }}

{{ 'To prevent misleading fits, trendline estimation requires minimum inclusion thresholds based on usable years (verified complete annual or seasonal records, where missing values are never treated as zero):' | translate }}

  • {{ 'Full Record:' | translate }} {{ 'At least 20 usable years and at least 70% data completeness across the full record.' | translate }}
